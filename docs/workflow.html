🎬 VideoJSON

動画 → JSON → 再生成 ワークフロー完全ガイド

Mission

ユーザーが 動画URLまたはMP4ファイルを渡すだけで、

  1. 動画を 構造化（JSON化）
  2. そのJSONを基に Shorts/長編を再生成
  3. さらに 差分編集で効率的に修正・展開

コアJSON成果物

📊 Event JSON

観測データ - シーン、エンティティ、テキスト検出結果

✏️ Authoring JSON

編集可能な制作データ - 台本、ロール、スタイル

📋 Plan JSON

実行計画 - セグメント、トランジション、BGM

🗄️ State JSON

完全状態 - 監査・再現・比較用

ジョブ詳細

INGEST 動画取り込み

YouTube URL / HTTP URL / GCS URI / ローカルMP4

PENDING → QUEUED → RUNNING → SUCCEEDED

出力: normalized.mp4, SHA256, media_info.json

ANALYZE AI解析

TwelveLabs + Gemini + Whisperでシーン分割・イベント抽出

PENDING → RUNNING → WAITING_EXTERNAL → REVIEW_REQUIRED → SUCCEEDED

出力: event.json v1.1

OCR テキスト検出

Cloud Vision / PaddleOCR / Tesseract

PENDING → RUNNING → REVIEW_REQUIRED → SUCCEEDED

出力: ocr_report.json, suggested_style_patch

EMBED 顔認識・人物同定

InsightFace + GFPGAN（顔補正）

PENDING → RUNNING → REVIEW_REQUIRED → SUCCEEDED

出力: embedding_report.json, entity_linking

HIGHLIGHT ハイライト抽出

重み付けスコアリング + LLM Rerank

PENDING → RUNNING → REVIEW_REQUIRED → SUCCEEDED

出力: highlight_plan.json

RENDER 動画レンダリング

FFmpeg / ComfyUI（Generative）

PENDING → RUNNING → WAITING_EXTERNAL → SUCCEEDED

出力: clip_manifests, draft.mp4

ASSEMBLE 最終合成

字幕（ASS）+ BGM + 顔スワップ

PENDING → RUNNING → SUCCEEDED

出力: final.mp4, state.json

TRAIN 学習ループ

フィードバック → 重み更新

PENDING → RUNNING → SUCCEEDED

出力: model_weights新バージョン

Non-Negotiables（絶対原則）

ID 原則 説明
P1 State保存 PromptではなくState JSONを保存し再現性を担保
P2 観測と制作の分離 Event JSON（観測）とAuthoring JSON（制作）を分離
P3 差分運用 base + JSON Patchで効率的な派生管理
P4 Human-in-the-loop 危険な自動適用禁止（style/人物統合など）
P5 ハイブリッド動画理解 ネイティブ動画AI + LLMの組み合わせ
P6 非同期＋冪等 Cloud Tasksで信頼性のあるジョブ実行
P7 Traceability Event→Authoring→Plan→Outputを辿れる
P8 権利/プライバシー 削除・アクセス制御・Secret管理
