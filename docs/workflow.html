VideoJSON ワークフロー（初心者向け）

目的：元動画を「構造（流れ）」としてJSON化し、台本・音声・人物（見た目）を差し替えて新しい動画を作る。

注意（必須）
元動画の"コピー"にならないように、台本は必ず書き換えます。
声・顔画像は本人の許可がある素材のみ使用します。

全体の流れ

[元動画] → [解析] → [structure.json] → [台本生成] → [narration.md]
                           ↓
                    [画像/音声アセット]
                           ↓
                     [render.json]
                           ↓
                [RENDER / ASSEMBLE]
                           ↓
                      [完成動画]

"どこを差し替えるか"

  • 台本：narration.md を差し替える（必須）
  • 音声：render.json の audio.mode と assets を差し替える
  • 人物（見た目）：render.json の lipsync 設定（顔画像asset）を差し替える
  • スタイル：render_mode と style_hint（または生成モデル設定）を差し替える

壊れないためのチェック

必ず schema validate を通す
structure.json → schemas/structure.schema.json
render.json → schemas/render.schema.json

詳細は docs/requirements.md と docs/spec.md を参照してください。
