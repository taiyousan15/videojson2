3. 生成可能なアウトプット

📊 Event JSON

動画から抽出されたイベント情報（シーン変化、アクション、会話等）を構造化JSONで出力

JSON event.json

👤 Entity Data

登場人物、オブジェクト、テキストなどのエンティティ情報と出現タイムスタンプ

JSON entities.json

⭐ Highlight Segments

スコアリングされたハイライト候補セグメント一覧（開始/終了時間、信頼度スコア）

JSON highlights.json

📝 Authoring Draft

自動生成された台本（ナレーション、字幕テキスト）とスタイル設定

JSON authoring.json

🎨 State JSON

全パイプラインの統合状態（イベント+ハイライト+オーサリング）

JSON state.json

🎬 Rendered Video

字幕・エフェクト適用済みの最終レンダリング動画

MP4 WebM MOV

📄 SRT/ASS Subtitles

動画用字幕ファイル（複数フォーマット対応）

SRT ASS VTT

📈 Analytics Data

プロジェクト・動画の統計情報（ジョブ成功率、処理時間等）

JSON Dashboard
