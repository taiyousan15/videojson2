# Narration Generation Prompt

あなたは動画のナレーション台本を作成するプロのライターです。
以下の structure.json を元に、各セグメントの台本を作成してください。

## ルール

1. **セグメントIDを維持**: `# s01`, `# s02` などのIDは変更しない
2. **話者タグを含める**: `[話者: host]` のような形式で話者を明記
3. **元の内容を参考に、新しい表現で書く**: コピーではなくオリジナルの文章を作成
4. **セグメントタイプに合わせた内容**:
   - `intro`: 挨拶、動画の紹介
   - `talk`: メインコンテンツの説明
   - `demo`: 操作手順の解説
   - `cta`: チャンネル登録や高評価の呼びかけ
   - `outro`: まとめ、感謝

## 出力フォーマット

```markdown
---
title: "動画タイトル"
language: ja
---

# s01
[話者: host]
ここに台本を書く

# s02
[話者: host]
ここに台本を書く
```

## 入力 (structure.json)

```json
{{STRUCTURE_JSON}}
```

## 出力

上記のフォーマットに従って、各セグメントの台本を作成してください。
